# 方剂学 · 背诵卡片与练习

一个**完全离线**的方剂学学习工具：把《方剂学》（第六版，中国中医药出版社）的每首方剂做成卡片，支持笔记、收藏、编辑、批量隐藏，提供**默写**与**选择题**两种练习，还有**方剂鉴别**检索与**两方组成对比**。

内容全部来自教材整理稿，未引入任何外部资料；所有数据只存本机，不上传、不联网。

- 在线使用（iPhone / Android 浏览器）：**https://kkjj405.github.io/fangjixue/**
- 安卓安装页（扫码下载 APK）：**https://kkjj405.github.io/fangjixue/install.html**
- 当前版本：**v1.0.2**（versionCode 3，`com.kkjj405.fjx`，最低 Android 5.0）

## 功能

### 背诵卡片
- **目录**：21 章 → 67 节 → 236 首正方 + 223 首附方；点方名进卡片
- **卡片顺序**：组成 → 方歌 → 功用 → 主治 → 运用 → 方解（君臣佐使）→ 附方及鉴别
- **翻页**：上一个/下一个只在 236 首正方间按目录切换，已隐藏的自动跳过；附方不参与翻页
- **长卡片分页**：正常数据整卡一页，只有内容超过约 2 屏才均衡分页，可切回连续阅读
- **笔记**：卡片内展开编辑区（不是弹窗），每首方剂一条
- **收藏**：支持分组（新建/重命名/删除/移动）
- **编辑**：组成 / 方歌 / 功用 / 主治 / 运用 / 方解 均可改，随时恢复原文
- **隐藏**：目录「管理」里批量勾选隐藏（目录中显示删除线），也可批量取消
- **鉴别**：母方与其附方的鉴别放在各自卡片内；不同方剂之间的鉴别在「方剂鉴别」板块

### 默写练习
选择范围（整章 / 整节 / 单首）与内容（组成、功用、主治、君臣佐使），看方名默写：
- 组成**不用写剂量**
- 君臣佐使按该方实际角色给方框（没有佐药/使药就少几个框）
- 教材没写君臣佐使结构的 48 首方照样出题，会提示并给「跳过」按钮，点一下视作完成
- 提交即显示答案；退出弹窗确认并自动保存，可同时保留 5 份练习记录

### 选择题练习
选项数量按比例生成、干扰项随机；君臣佐使拆成 4 个小题，同一页可上下滑动作答。

### 方剂组成对比
任选两首方 → 自动列出「共同含有的药」「只有 A 有」「只有 B 有」；药名做了炮制/别名归一（如 甘草 = 炙甘草 = 生甘草，白芍 = 芍药）。

### 其他
- 按方名搜索、方剂鉴别检索
- 打赏页（原文案 + 收款码）
- 检查更新 / 热更新（Android）
- 首页三条公告（教材依据与免责声明、分享、赞赏入口）

## 数据

| 项 | 数量 |
|---|---|
| 章 / 节 | 21 章 / 67 节（两章教材未分节） |
| 正方 | 236 首 |
| 附方 | 223 首（前言写 222，实际条目 223） |
| 方剂间鉴别 | 90 条 |
| 母方-附方鉴别 | 140 条 |
| 无君臣佐使结构 | 48 首（教材注明，练习可跳过） |

### 已知说明
- 教材本身有 10 首方的方解用到组成里没列的药（如紫雪用麝香/硝石/朴硝），属原文内部不一致，程序如实呈现、不替教材补药
- 6 首附方（知柏地黄丸等）组成是「即某方加某药」的派生写法，程序不拆药名，不参与练习
